# Medoz TV — تطبيق Tizen

أول نموذج تنفيذي لواجهة Medoz TV العربية. التصميم والكود مستقلان ولا يعيدان استخدام شيفرة أو أصول Morph TV.

## الموجود في هذه الدفعة
- واجهة RTL كحلي وذهبي، مع أقسام رئيسية واضحة.
- التنقل بين الرئيسية والقرآن والأذكار والرقية والراديو والصوتيات والمفضلة والإعدادات.
- الساعة والتاريخ المحليان، والأذكار مع عدّاد محفوظ محليًا.
- إعداد المدينة والثيم وتقليل الحركة وتخزين التفضيلات.
- تشغيل رابط بث مباشر وملف صوتي عند دعم الجهاز.
- المفضلة المحلية وزر رجوع أساسي.
- ملف إعداد أولي لـ Samsung Tizen.

## يحتاج استكمالًا
- نص المصحف وفهرس السور والتلاوات الموثقة.
- حساب مواقيت الصلاة والأذان من مزود موثوق وبيانات طقس.
- تطبيق موبايل والاقتران والتحكم بالتلفزيون.
- مصادر IPTV قانونية، وتوقيع الحزمة واختبار التلفزيون.

## اختبار محلي
افتح apps/tizen-tv/index.html في متصفح حديث. لاختبار التلفزيون استخدم Tizen Studio وTV profile، وتحقق من معرّفات الحزمة ومتطلبات SDK والتوقيع قبل التثبيت.

**الحالة:** نموذج أولي قابل للتجربة، وليس إصدارًا نهائيًا أو ضمانًا للتوافق مع جميع موديلات Samsung.
