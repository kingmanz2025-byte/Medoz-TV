# Medoz TV — Release Checklist

## Product and design
- [ ] Final design reviewed and approved.
- [ ] Arabic RTL verified on the target TV.
- [ ] Navy-and-gold focus states are readable.
- [ ] No clipped text, overlapping cards, or broken images.

## Functionality
- [ ] Remote navigation works across every screen.
- [ ] Clock uses 12-hour Arabic ص/م format.
- [ ] Prayer order is correct and sunrise is informational.
- [ ] Next-prayer calculation is tested across midnight.
- [ ] City selection and offline behavior work.
- [ ] Weather data freshness is clear.
- [ ] Supported audio playback and recovery are tested.
- [ ] Favorites and settings persist as intended.

## Security and rights
- [ ] No unauthorized copyrighted media or channel lists bundled.
- [ ] Permissions are necessary and explained.
- [ ] User credentials and sensitive URLs are not exposed in logs.
- [ ] Installation follows platform rules.

## Compatibility and stability
- [ ] Exact TV model, firmware, and Tizen version recorded.
- [ ] Installation and launch tested on the target device.
- [ ] Offline and slow-network tests passed.
- [ ] Long-session playback and memory use checked.
- [ ] Unsupported features are not advertised as working.

## Release materials
- [ ] Version and change notes prepared.
- [ ] Installation instructions reviewed.
- [ ] Known limitations documented.
- [ ] Source and release artifacts backed up.
