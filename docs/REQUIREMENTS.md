# Medoz TV — وثيقة المتطلبات

**الإصدار:** 0.1  
**الحالة:** مسودة معتمدة مبدئيًا، قيد استكمال التفاصيل  
**المنصة المستهدفة:** Samsung Tizen Smart TV  
**جهاز الاختبار الأول:** Samsung UA7000، 58 بوصة

## 1. الأهداف والمبادئ
1. تطبيق مستقل باسم Medoz، بتصميم جديد بالكامل.
2. جميع وظائف التطبيق مجانية، بلا اشتراكات أو مشتريات داخل التطبيق.
3. تجنب الإعلانات داخل التطبيق.
4. دعم العربية وRTL.
5. دعم أكبر قدر ممكن من العمل دون اتصال.
6. عدم بدء البرمجة قبل اعتماد المتطلبات والتصميم.
7. التوزيع العام يجب أن يراعي التوافق والتوقيع وشروط Samsung.

## 2. المكونات
- تطبيق تلفزيون مستقل متوافق مع Tizen.
- تطبيق موبايل للاتصال والتحكم، والمساعدة في التثبيت حيث تسمح المنصة.
- صفحة مشروع/تنزيل يمكن استضافتها مجانًا.
- توثيق للإصدارات والتوافق.

## 3. الوظائف
### الواجهة والثيمات
- تصميم جديد بالكامل.
- خلفيات وألوان وأحجام وترتيب عناصر قابل للتخصيص.
- معاينة واستعادة الإعدادات الافتراضية.
- جميع الثيمات مجانية.

### الاتصال والتثبيت
- اكتشاف التلفزيون أو إدخال IP يدويًا.
- إظهار حالة الاتصال والأخطاء.
- تثبيت الحزمة عبر آلية متوافقة مع الجهاز وإعدادات الأمان.
- دعم تحديثات مستقبلية عند توفر طريقة توزيع مناسبة.

### الريموت والتطبيقات
- الاتجاهات والتأكيد والرجوع والرئيسية.
- أوامر الصوت والكتابة والتشغيل حيث تدعمها المنصة.
- إدارة اختصارات التطبيقات المتاحة؛ إخفاء الاختصار لا يحذف التطبيق الأصلي.

### الصلاة والأذان
- الصلوات والشروق، الصلاة القادمة، المدينة وطريقة الحساب.
- تنبيهات وصوت أذان وفق إمكانيات التلفزيون.
- حفظ آخر مواقيت متاحة محليًا وتوضيح أنها قديمة عند عدم التحديث.

### الراديو والقرآن والرقية
- بث إنترنت وملفات صوتية محلية.
- قوائم تشغيل ومفضلة وتكرار وتشغيل/إيقاف.
- نقل الملفات من الموبايل أو اختيار مصدر محلي — آلية النقل ما زالت بحاجة إلى قرار.
- التشغيل بالخلفية رهن دعم Tizen واختباره.

### الساعة والطقس
- ساعة وتاريخ محليان.
- الطقس يحتاج اتصالًا بمصدر بيانات؛ يمكن الاحتفاظ بآخر نتيجة مع إظهار وقت تحديثها.

### IPTV
- دعم مصادر واشتراكات قانونية ومتوافقة فقط.
- لا تُضمّن قنوات أو اشتراكات مدفوعة غير مرخصة.

### العائلة والحماية
- ملفات تعريف وقفل PIN داخل التطبيق.
- نطاق الحماية وحدودها بحاجة إلى اختبار المنصة.

### إرسال المحتوى
- دعم بروتوكولات مثل DLNA حيث يتوفر جهاز متوافق.

## 4. العمل دون إنترنت
يستهدف التطبيق العمل محليًا في: الواجهة والثيمات المحفوظة، الساعة والتاريخ، الأذكار والملفات الصوتية المحلية، الإعدادات والمفضلة، وآخر مواقيت محفوظة. البث والطقس المحدث وتحديث مكتبات IPTV تحتاج الإنترنت غالبًا.

## 5. التوزيع والتكلفة
- GitHub لحفظ المصدر وإدارة الإصدارات.
- GitHub Pages لصفحة معلومات ثابتة عند الحاجة.
- GitHub Releases لتوزيع الملفات التجريبية عند جهوزيتها.
- النشر في متجر Samsung مسار منفصل يخضع لمتطلبات الاعتماد.
- GitHub لا يقوم بذاته بتثبيت تطبيق Tizen ولا يوفر خادم مزامنة خلفيًا.

## 6. اختبارات إلزامية
- التثبيت والتوقيع على إصدار Tizen المستهدف.
- الاتصال من الموبايل.
- أوامر الريموت والصوت.
- تشغيل الراديو والملفات المحلية والخلفية.
- توقيت الأذان.
- حفظ الإعدادات واستعادتها.
- انقطاع الإنترنت واستعادة الاتصال.
- الأداء والاستقرار طويل المدى.

## 7. قرارات مفتوحة
- التصميم التفصيلي للشاشة الرئيسية.
- اسم الحزمة ومعرّف التطبيق.
- آلية نقل ملفات الصوت.
- مصادر البث الموثوقة.
- نطاق الرقابة الأبوية.
- التشغيل التلقائي بعد تشغيل التلفزيون.
- طريقة النشر النهائي ودعم موديلات Tizen المختلفة.
