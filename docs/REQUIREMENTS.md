# Medoz TV — Requirements

## 1. General
- Project name: Medoz TV.
- Target: Samsung Tizen Smart TVs.
- Companion platform: Android.
- Language: Arabic with right-to-left layout.
- Cost: Free, with no subscriptions or paid themes.
- Design: Original identity, not a copy of Morph TV.

## 2. TV Application
- Main dashboard with customizable themes and backgrounds.
- App shortcuts where supported by the TV.
- Remote-control navigation using TV remote buttons.
- Clock, date, prayer times, and optional adhan.
- Quran, azkar, ruqyah, and radio playback.
- Local audio playback and compatible online streams.
- Favorites and family profiles with optional PIN.
- IPTV support for compatible legal sources.
- Casting or DLNA where technically supported.

## 3. Android Companion
- Discover and connect to a compatible TV.
- Display connection status and TV IP address.
- Provide remote-control functions where supported.
- Assist with TV app installation only through supported methods.

## 4. Offline Operation
- Save preferences, themes, and favorites locally.
- Play supported local audio files.
- Display the device clock and date.
- Retain previously saved prayer-time settings.
- Clearly indicate features that require internet access.

## 5. Design Approval
Before implementation, review:
- Home screen layout.
- Colors, typography, and icon style.
- Navigation and remote-control behavior.
- Arabic RTL layout.
- Android companion interface.

## 6. Testing
- Confirm exact Samsung TV model and Tizen version.
- Test installation, navigation, playback, and connectivity.
- Document unsupported features and device limitations.

## 7. Current Status
Requirements and design approval are in progress. No implementation should begin until the user approves the proposed design and feature scope.
