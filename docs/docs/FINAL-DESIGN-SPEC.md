# Medoz TV — Final Design Specification

## Visual Identity
- Premium dark navy and gold.
- Cinematic backgrounds and polished service cards.
- Arabic interface with right-to-left layout.
- Fixed sidebar navigation.
- Large cards with a clear gold focus indicator for remote control.

## Home Screen
- Clock and date.
- Prayer times in correct chronological order.
- Small weather card.
- Large service cards.
- Upcoming prayer countdown.
- Favorite application shortcuts.

## Time and Location
- Display clock and prayer times in 12-hour format with Arabic AM/PM indicators (ص/م).
- Use the device time zone when available.
- Request location permission only where supported and permitted.
- Allow manual city selection as a reliable fallback.
- Calculate prayer times using the selected location and calculation method.
- Show weather updates when an internet connection is available.
- Keep cached information offline and identify stale data clearly.

## Services
- Quran audio.
- Azkar and ruqyah.
- Radio and local audio files.
- Prayer times and adhan settings.
- Weather.
- Custom themes and backgrounds.
- Android companion and remote control where supported.
- App shortcuts where permitted.
- IPTV from compatible legal sources.
- Casting where compatible.

## Offline-First
- Save preferences, themes, and favorites locally.
- Support local audio files where possible.
- Preserve saved location and prayer settings.
- Clearly identify features that need internet access.

## Compatibility
- Test on the target Samsung TV and its Tizen version.
- Verify installation, remote navigation, audio playback, location options, and casting before promising support.

## Development Gate
This document defines the intended design and requirements. Do not begin implementation until the user explicitly approves the final design.
