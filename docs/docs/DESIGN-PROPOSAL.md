# Medoz TV — Design Proposal

## 1. Visual Identity
- Project name: Medoz TV.
- Style: Modern, premium, clean, and easy to use from a sofa.
- Primary colors: Deep navy and gold.
- Backgrounds: Dark navy and charcoal, with high-contrast text.
- Language: Arabic RTL, with readable typography.
- Design must be original and independent.

## 2. TV Home Screen
Proposed layout:
- Header: time, date, and connection status.
- Main area: large navigation cards.
- Audio section: Quran, azkar, ruqyah, and radio.
- Utilities: prayer times, weather, and favorites.
- Settings: themes, audio sources, family profiles, and privacy.

## 3. Remote Control
- Navigate with directional buttons.
- Select with OK/Enter.
- Return with Back.
- Visible focus indicator around the selected item.
- Avoid tiny text and crowded menus.

## 4. Android Companion
- Simple dashboard showing TV connection status.
- TV discovery and manual IP entry.
- Remote-control screen where supported.
- Installation assistance only through compatible methods.

## 5. Offline-First Experience
- Save preferences and favorites locally.
- Support local audio playback where available.
- Keep saved settings accessible without internet.
- Clearly show when a feature needs an internet connection.
